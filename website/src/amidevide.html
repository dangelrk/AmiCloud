AmiDevIDE

Version {{v:amidevide}}Amiga · Mac und PC folgen AmiDevIDE auf Aminet

Amiga-Software in C, Assembler oder ACE BASIC entwickeln, auf dem Amiga oder am PC. Beide Fassungen von AmigaIDE teilen sich dieselben Projektdateien.

In dieser Anleitung
  1. Einrichten
  2. Ein Projekt anlegen
  3. Bauen und starten
  4. Versionsverwaltung
  5. Mehr erfahren

Einrichten

Auf dem Amiga

  1. Lade AmiDevIDE.lha von Aminet, packe es aus und starte Install-AmiDevIDE. AmigaIDE braucht MUI und vbcc; welche Bibliotheken dazukommen, steht im Handbuch.
  2. Trage die Pfade zum Compiler und zu den SDKs in S:User-Startup ein und passe sie an dein System an: 
    Assign vbcc: Work:vbcc
Path vbcc:bin ADD
Assign SDK: Work:SDK
Stack 65536
  3. Starte AmigaIDE per Doppelklick. Die Titelzeile zeigt, wann die Version gebaut wurde.

Am Mac und PC

Die Fassung für Mac, Linux und Windows folgt mit der Veröffentlichung auf GitHub. Die Bilder aus der Mac-Fassung auf dieser Seite zeigen, wie sie aussieht; die Bedienung entspricht weitgehend der Amiga-Fassung.

Ein Projekt anlegen

Die Bilder in diesem Abschnitt stammen aus der kommenden Mac-Fassung. Die Menünamen hier gelten für das Amiga-Programm.

  1. Wähle Projekt › Neu…, dann Ordner, Sprache und Art des Programms.
  2. Füge über Projekt › Neue Datei Quelltexte hinzu. Sie erscheinen im Projektbaum links und öffnen sich mit einem Doppelklick im Editor. {{fig:ide-qt-haupt|Projektbaum, Editor und Ausgabe in der kommenden Mac-Fassung nach einem erfolgreichen Build.}}
  3. Unter Projekt › Projekteinstellungen… stellst du Compiler, Linker, SDKs und das Startverhalten ein. {{fig:ide-qt-projekt|Die Projekteinstellungen in der kommenden Mac-Fassung.}}

Liegen Compiler oder SDKs woanders oder heißt make anders, änderst du das unter Projekt › Einstellungen….

Bauen und starten

  1. Build › Build (Amiga+B) speichert, erzeugt ein Makefile und baut im Hintergrund. Die Ausgabe läuft unter Ausgabe, Fehler stehen unter Issues. {{fig:ide-mui|AmigaIDE auf dem Amiga nach einem erfolgreichen Build.}}
  2. Memory Map zeigt danach die Hunks des Programms. {{fig:ide-qt-speicher|Die Memory Map in der kommenden Mac-Fassung.}}
  3. Build › Run (Amiga+R) startet das Programm.

Versionsverwaltung

AmigaIDE benutzt AmiVCS als eigenes Programm. Ist AmiVCS installiert, zeigt das Register Versionen Änderungen und Branches, und Verlauf zeigt die Historie. Geänderte Dateien sind im Projektbaum markiert.

{{fig:ide-qt-vcs|Änderungen, Commit und Historie in der kommenden Mac-Fassung.}}
