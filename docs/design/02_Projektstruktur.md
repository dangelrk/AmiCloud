# Zielstruktur

``` text
client/
  amicloud/
  amicloud-shell/
  amicloud-commander-mui/
  amicloud-commander-qt/
  cloudsync/

libs/
  libcloudcore/
  libcloudhttp/
  libcloudfs/
  libcloudsync/

handler/
  cloudhandler/

server/
  php/
```

libcloudcore enthält gemeinsame Datentypen. Alle Anwendungen verwenden
dieselben Bibliotheken.
