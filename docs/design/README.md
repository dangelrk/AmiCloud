# Historische Planungsdokumente

Die Dateien in diesem Ordner sind Design- und Stufenpläne aus der Zeit vor
der Aufteilung des alten Monorepos in AmiCloud, AmiOwnCloud, AmiVCS und
AmiCloudCore. Sie werden nicht nachgeführt: Pfade darin (`client/apps/`,
`client/common/`, `libs/`, `docs/architecture/` …) beziehen sich auf das
alte Monorepo – heute liegen die Programme unter `apps/`, die Bibliotheken
unter `core/` (AmiCloudCore). Aktuelle Doku: [README.md](../../README.md),
[BUILD.md](../BUILD.md), [INSTALL.md](../INSTALL.md).
